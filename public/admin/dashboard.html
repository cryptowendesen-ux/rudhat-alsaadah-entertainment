⚙️ Contact, Hours & Booking Rules

Prices are edited in the Prices and Birthday sections below. They update everywhere on the website automatically (hero, FAQ, birthday section, WhatsApp messages). The item titled “Per Hour” is used as the hourly price. Birthday packages: add one item per package in the Birthday section — Title = package name, Price, and in Description write one included item per line. With 2 or more packages, customers choose a package when booking. Booking rules: a pending or confirmed booking holds its time; cancelled bookings free it.

Staff can see and confirm bookings and run play cards. They cannot change website content, settings, closed days, accounts or statistics, and cannot delete anything. Give each person their own account.

📈 Website Visitors

Visits per day

Anonymous counters only: no cookies and no personal data. A visit is counted once per browser session. Taps are counted when someone presses a WhatsApp, call or map button, or opens the booking form.

🔒 Security

Sessions last 8 hours. If a phone was lost, or someone else knew your password, sign out every device and then change ADMIN_PASSWORD in Render.
Two-step verification
Asks for a 6-digit code from an app (Google Authenticator, Authy or Microsoft Authenticator) every time the owner signs in. If you ever lose the phone: set DISABLE_OWNER_2FA=true in Render, sign in, then set it up again.
