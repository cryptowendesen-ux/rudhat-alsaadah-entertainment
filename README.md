# RUDHAT ALSAADAH ENTERTAINMENT
Complete starter package based on the supplied V4 website, with Node/Express backend and authenticated admin CRUD API.

Run: copy `.env.example` to `.env`, set secrets, run `npm install`, then `npm start`.

The supplied V4 homepage is preserved in `public/index.html`. Its visible dashboard is still a front-end demo; the backend API is now prepared for wiring to the dashboard.
